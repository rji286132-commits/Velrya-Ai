# 🔥 Virya AI - AI Website Builder

## Features
- 🤖 AI-powered website generation
- 💬 Chat interface
- 📁 File upload support
- 🖥 Live preview
- 📋 Code export
- 🔐 User authentication
- 👑 Super Admin dashboard

## Setup
1. Clone this repo
2. `npm install`
3. Create `.env.local` with your keys
4. `npm run dev`
